# Bancos externos úteis

Use esta lista para procurar material quando o banco interno não tiver o que precisamos.

## Pixabay

- Imagens: https://pixabay.com/images/search/
- Vídeos: https://pixabay.com/videos/search/
- Música: https://pixabay.com/music/
- SFX: https://pixabay.com/sound-effects/
- Licença: https://pixabay.com/service/license-summary/

**Importante:** a licença atual do Pixabay proíbe distribuir o conteúdo em formato standalone. Então não vamos copiar arquivos novos do Pixabay para este GitHub como se fossem nossos. Eles podem ser usados dentro de uma edição/obra nova conforme a licença.

## Pexels

- Fotos: https://www.pexels.com/search/
- Vídeos: https://www.pexels.com/videos/
- Licença: https://www.pexels.com/license/

## Unsplash

- Fotos: https://unsplash.com/
- Licença: https://unsplash.com/license

## Mixkit

- Vídeo: https://mixkit.co/free-stock-video/
- Música: https://mixkit.co/free-stock-music/
- SFX: https://mixkit.co/free-sound-effects/
- Licença: https://mixkit.co/license/

## Wikimedia Commons

- Busca: https://commons.wikimedia.org/wiki/Special:MediaSearch

Ótimo para encontrar material Public Domain e CC0. Sempre verificar a licença do arquivo individual antes de baixar para o repositório.

## NASA

- Biblioteca de imagens e vídeos: https://images.nasa.gov/
- Scientific Visualization Studio: https://svs.gsfc.nasa.gov/

Material da NASA pode ter regras de crédito, marcas e uso específicas. Guardar a página de origem junto no catálogo.

## Como usamos

1. Preferir assets criados por nós em `graphics/`, `images/backgrounds/` e `audio/sfx/`.
2. Para material externo, procurar primeiro Public Domain/CC0.
3. Se a licença não permitir redistribuição standalone, guardar **link + licença**, não o arquivo bruto.
4. Sempre registrar a origem em `external-sources/`.
