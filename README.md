# assets-videos

Biblioteca de assets para edição de vídeo, motion design e projetos 

## Estrutura

- `graphics/svg/` — elementos vetoriais editáveis
- `audio/sfx/` — efeitos sonoros criados para o repositório
- `video/overlays/` — overlays e transições de vídeo
- `external-sources/` — bancos externos e regras de licença
- `catalog.md` — índice rápido dos assets

## Regra principal

Assets em `graphics/`, `audio/` e `video/` foram criados para este repositório sem incorporar arquivos de bancos terceiros.

Conteúdo de Pixabay, Mixkit e outros bancos não é reupado aqui quando a licença proíbe redistribuição standalone. Nesses casos, deixamos links e instruções em `external-sources/`.
